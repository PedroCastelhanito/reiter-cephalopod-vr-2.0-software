# Tasks

Open work by status. Entry rules: [AGENTS.md](AGENTS.md#task-and-change-tracking).
Completed work moves to [LOG.md](LOG.md); decisions live in the architecture records and
detailed findings in the backend reports. Listing a task does not authorize an
implementation stage or lift a deferral, and local completion never closes a rig check.

Entry format: `- [ ] \`task-id\` [backend] ... Action. Done when: ... Status: ... — links`.
Blocked and Deferred entries name their reason.

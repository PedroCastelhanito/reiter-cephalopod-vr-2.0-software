Behavior implemented
- Shared exact nominal grid selects half-open slots from the unchanged T and rational cadence. Acquisition selects by camera host receipt; Visual Stimulus selects by evaluation_host_ns. Same-slot omissions remain distinct from transfer/capacity failure, with source facts preserved.
- Acquisition streams leading/interior/trailing duplicates through the existing prepared buffer after cutoff/producer completion. Each encoded submission advances watchdog/progress/sync and is included in encoded count; source and encoded counts/mapping are distinct. Existing finish deadline is retained.
- Visual Stimulus preserves group admission order despite out-of-order transfer completion, resolves first usable image as leading source, streams duplicates, and seals exact cutoff before waking the writer. It normalizes owned pixel data once on the recording owner; repeated rows do not flip twice. Required-grid admission replaces the test-only unpadded production branch.
- Visual Stimulus resource preflight accounts CPU peak `(capture_slots + 2) * (width * height * 4) + (width * 4)`: admitted slots, one retained source, one serialized PBO readback ownership-copy transient, and one row-swap scratch. Actual GPU reservation is compositor `pixels * 16` plus one RGBA PBO per capture slot. No new setting was added.
- Evidence schema/mapping carries encoded index, nominal slot, real source identity/time and duplicate disposition; source, encoded, duplicate, omission and failure counts remain separate.

Acquisition tail-watchdog correction and integrated session proof (2026-10-09)
- `EncoderProgressWatchdog.active_input_work()` scopes tail writes as pending encoder input even after the source queue drains. `check()` now combines real queue ownership with this explicit active operation. Successful scope exit clears pending state; failed writes preserve the first pending timestamp across retries. Actual progress-frame advancement alone updates the progress timestamp; repeated successful stdin writes do not renew the stall clock. `RecordingSession.finish()` scopes its trailing duplicate loop with this operation. Existing retained absolute finish deadline still bounds each write and is preserved across same-evidence retry.
- Acquisition `FrameLogWriter` now derives the rational cadence from the same canonical `_format_rate()` string sent to FFmpeg, avoiding float precision drift between nominal-slot mapping and the configured encoder input rate. Integrated session test asserts 29.97002997002997 is represented by the encoder's canonical 29.97002997 cadence.
